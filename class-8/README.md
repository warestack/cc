### Week 8: Apache Cassandra

In Week 8, you will run Apache Cassandra in Docker and practise basic Cassandra commands.

Complete the task in this order:

1. [Lab 1: Apache Cassandra with Docker and Python](lab/part-1.md)

#### What You Need To Do

- Start Cassandra containers with Docker.
- Build a small Cassandra cluster.
- Check cluster health with `nodetool`.
- Use `cqlsh` to create a keyspace and table.
- Insert and query Cassandra data.
- Connect to Cassandra from Python.
- Clean up the Cassandra containers.

> [!WARNING]
>
> Cassandra containers use a lot of memory. Use a VM with at least 8 GB RAM for this lab.
