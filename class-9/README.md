### Week 9: Distributed Communication with ZeroMQ

In Week 9, you will use ZeroMQ to practise communication patterns used in distributed systems.

Complete the task in this order:

1. [Lab 1: ZeroMQ Communication Patterns](lab/part-1.md)

#### What You Need To Do

- Create a Python virtual environment.
- Install `pyzmq`.
- Run Pair communication.
- Run Request/Reply communication.
- Run Publish/Subscribe communication.
- Run Push/Pull pipeline communication.
- Clean up any processes using the lab ports.

> [!WARNING]
>
> Socket programs can leave ports busy if they are not stopped. Use `Ctrl + C` to stop long-running processes.
