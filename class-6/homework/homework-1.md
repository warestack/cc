### Week 6 Homework 1: Docker Reflection Post

For homework, write a short post in the Teams collaboration space.

#### Topic

Research this question:

```text
Why is Docker useful when deploying APIs to the cloud?
```

#### What To Include

Write a short post with:

- one explanation of what a Docker image is
- one explanation of what a Docker container is
- one reason Docker helps when moving an API from a laptop to a cloud VM
- one screenshot from your Week 6 container running in the browser or Postman

#### Suggested Length

Write around 150 to 200 words.

#### Optional

If you want extra practice:

1. Create a Docker Hub account.
2. Find the official Python image on Docker Hub.
3. Write one sentence explaining why using official images is usually safer than using random images.

Do not upload secrets, passwords, tokens, or `.env` files to public repositories.
