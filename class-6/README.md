### Week 6: Docker and FastAPI Containers

In Week 6, you will use Docker to run applications inside containers.

Docker lets us package an application with the software it needs, so it can run in a predictable way on another machine.

Complete the tasks in this order:

1. [Part 1: Install Docker and Run Your First Containers](lab/part-1.md)
2. [Part 2: Containerize a FastAPI App](lab/part-2.md)
3. [Part 3: Docker Exercise](lab/part-3.md)
4. [Homework 1: Docker Reflection Post](homework/homework-1.md)

#### What You Need To Do

- Install Docker on the GCP VM from Week 5.
- Run the `hello-world` container.
- Pull and run an Ubuntu container.
- Create a Dockerfile for a FastAPI app.
- Build a Docker image.
- Run a FastAPI container.
- Test the container in the browser and in Postman.
- Practise basic Docker cleanup commands.

> [!WARNING]
>
> Stop your containers and stop your VM when you finish. Running cloud resources can spend your coupon credit.
