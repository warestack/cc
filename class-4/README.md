### Week 4: User Validation and Authentication

In Week 4, validate registration data, hash passwords and protect API routes with expiring JWTs. Then explain the architecture of your planned final application.

#### What You Need To Do

- Validate registration data and keep passwords out of responses.
- Store password hashes and authenticate users.
- Configure a private signing secret and issue expiring JWTs.
- Check successful and rejected requests with automated tests.
- Publish the practice app, tests and README in a new GitHub repository.
- Post a simple architecture diagram and a 200–300-word API journey in Teams.
