### Week 2: SQLite and FastAPI

In Week 2, you will first work with SQLite directly, then connect a FastAPI app to a SQLite database.

Complete the tasks in this order:

1. [Part 1: Create a Local SQLite Database](lab/part-1.md)
2. [Part 2: Show SQLite Data with FastAPI](lab/part-2.md)
3. [Part 3: SQLite and FastAPI Exercise](lab/part-3.md)
4. [Homework 1: Simple CRUD with FastAPI and SQLite](homework/homework-1.md)
5. [Homework 2: Test APIs with Postman](homework/homework-2.md)

#### What You Need To Do

- Create a SQLite database locally.
- Create a table.
- Insert rows using SQL commands.
- Read rows using SQL commands.
- Build a simple FastAPI app that reads from SQLite.
- Show database data in the browser.
- Complete a short SQLite and FastAPI exercise.
- Build a simple CRUD API as homework.
- Use Postman to make API calls as homework.
