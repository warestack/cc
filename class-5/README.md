### Week 5: GCP, VM, Linux, and Cloud Setup

In Week 5, you will move from local API development to cloud work.

You will redeem your GCP coupon, create a virtual machine, connect to it, create a safe lab user, and practise the Linux commands you need for Docker and deployment.

Complete the tasks in this order:

1. [Part 1: GCP Coupon and First Virtual Machine](lab/part-1.md)
2. [Part 2: SSH, Lab User, and Sudo](lab/part-2.md)
3. [Part 3: Linux Commands for Cloud Work](lab/part-3.md)
4. [Homework 1: VM and Linux Exercise](homework/homework-1.md)
5. [Homework 2: Cloud and Sudo Research Post](homework/homework-2.md)

#### What You Need To Do

- Request and redeem your GCP coupon.
- Create a GCP project.
- Enable Compute Engine.
- Create an Ubuntu virtual machine.
- Connect to the VM using SSH.
- Create a Linux lab user and make the user a sudo user.
- Practise the Linux commands needed for cloud work.
- Complete the VM and Linux exercise as homework.
- Stop or delete cloud resources when you finish.

> [!WARNING]
>
> Do not leave cloud resources running when you are not using them. Running resources can spend your coupon credit.
