### Week 7: Kubernetes on GCP

In Week 7, you will deploy a containerised FastAPI application to Kubernetes using Google Kubernetes Engine.

Complete the task in this order:

1. [Lab 1: Deploy FastAPI on Kubernetes with GKE](lab/part-1.md)

#### What You Need To Do

- Prepare a small FastAPI app.
- Build a Docker image.
- Push the image to Docker Hub.
- Create a Kubernetes cluster on GCP.
- Deploy the app with a Kubernetes Deployment.
- Expose the app with a LoadBalancer Service.
- Scale the app to multiple replicas.
- Update the app image.
- Clean up the Kubernetes resources and cluster.

> [!WARNING]
>
> Kubernetes clusters can spend cloud credit quickly. Delete the cluster when you finish the lab.
