### Week 3: SQLAlchemy and Validation

In Week 3, you will rebuild the Week 2 database API using SQLAlchemy.

SQLAlchemy lets Python code work with SQL tables using models and sessions. This is the style we will use before moving to larger APIs and authentication.

Complete the tasks in this order:

1. [Part 1: Create a Local SQLite Database with SQLAlchemy](lab/part-1.md)
2. [Part 2: Build a FastAPI App with SQLAlchemy](lab/part-2.md)
3. [Part 3: Add Pydantic Validation](lab/part-3.md)
4. [Homework 1: SQLAlchemy Exercise](homework/homework-1.md)

#### What You Need To Do

- Create a new project in VS Code.
- Install FastAPI, Uvicorn, and SQLAlchemy.
- Create a SQLite database using SQLAlchemy models.
- Read and write data using a SQLAlchemy session.
- Add request validation with Pydantic schemas.
- Complete the SQLAlchemy exercise as homework.
